# Model card — DebtScope AI production forecast

- **Model name:** `mean-log-growth` (historical average log-growth extrapolation)
- **Version:** `wf-2026-03-31` (versions are `wf-<data-through-date>`; regenerated by `npm run models:evaluate`)
- **Intended use:** transparent, reproducible national-debt trend context at 1–20 year horizons for education, journalism, and policy discussion.
- **Prohibited use:** investment decisions, budget scoring, partisan attribution of debt outcomes, or presentation as an official government projection.
- **Target variable:** nominal total public debt outstanding (Treasury GFDEBTN, quarterly, re-dated to true quarter-end as-of dates). Nominal is modeled because it is the observable policy quantity; because the target is nominal, forecasts embed historical price-level behavior and must not be read as purchasing-power statements. Real (CPI-U, 2025-dollar) restatements are applied only to observed history, never double-applied to forecasts.
- **Features:** lagged values of the target series only (univariate). No macro covariates yet — adding them requires vintage-aware (as-first-published) data to avoid leakage; see roadmap.
- **Data sources:** see `DATA_SOURCES.md` / `DATA_LINEAGE.md`. All committed snapshots come from Treasury Fiscal Data and FRED (BLS, BEA, OMB, Census series).
- **Training period:** 1966-Q1 onward; first walk-forward origin after 80 quarters (≈1986), 160 rolling origins through 2026-Q1.
- **Validation design:** rolling-origin walk-forward. At each origin the model is refitted on data up to that origin only and scored out-of-sample at 1-quarter, 1-year, and 5-year horizons. No random splits, no full-sample scaling, no tuning on the test period.
- **Performance (out-of-sample, data through 2026-03-31):** see `MODEL_COMPARISON.csv` for the full table. Headline: 1-quarter MAPE ≈ 1.1%, 1-year MAPE ≈ 3.2%, 5-year MAPE ≈ 13.5%; mean MASE across 1y/5y = 15.86 vs 28.79 for the best naive baseline (naive-drift). MASE is scaled by the typical one-quarter move at the origin, so long-horizon values are naturally ≫ 1; comparisons across models are what matter.
- **Baseline comparison:** three naive baselines (last value, drift, last growth rate) plus trailing 5y/10y CAGR, 10y linear trend, and 10y exponential trend. The production model must not lose to the best naive baseline; today it beats every alternative at both selection horizons.
- **Forecast horizons:** 1–20 years, annual steps, generated on request from the committed evaluation artifact + committed data.
- **Prediction intervals:** empirical 10th–90th percentile of out-of-sample annualized-growth errors at the 5-year horizon (q10 = −7.0pp, q90 = +1.7pp of annual growth), estimated on the first half of origins and coverage-verified on the held-out second half (observed 79% vs 80% nominal). These are evidence-based ranges, not formal Bayesian prediction intervals; the asymmetry is real (the model over-predicted growth during the 1990s surplus era).
- **Known limitations:** univariate trend persistence; no representation of legislation, debt-ceiling mechanics, interest-rate regime changes, recessions, or emergencies; quarterly data with ~2-month publication lag; assumes upstream revisions are honest history (vintage data not used).
- **Ethical and communication risks:** debt figures are politically charged. The UI states everywhere that presidents do not independently control debt, that model output is not an official projection, and that scenario results depend entirely on user assumptions.
- **Retraining schedule:** the scheduled data-refresh workflow re-runs the full evaluation weekly and after every data refresh; the artifact is only committed when validation and tests pass.
- **Monitoring:** CI re-derives the evaluation from committed data on every push (reproducibility gate); holdout interval coverage is recomputed and displayed in the UI.
- **Rollback procedure:** every artifact is a versioned git commit; reverting the commit restores the previous model, data, and UI state atomically.
- **Prediction metadata:** every forecast response carries model id, artifact version, data-through date, evaluation timestamp, selection rule, and interval definition (`/api/forecast` → `meta`).

## Selection rule

Lowest mean out-of-sample MASE across the 1-year and 5-year horizons, with the hard constraint that the selected model must not underperform the best naive baseline at those horizons. A more complex model that loses to a naive baseline is never promoted, and "AI" is never used as a reason to prefer complexity.

## Roadmap

1. Macro-covariate candidates (rates, deficits, GDP) using vintage-aware data.
2. CBO long-term projection overlay, clearly labeled as an official third-party product.
3. Per-horizon interval recalibration on every scheduled refresh.
4. Debt-to-GDP as an alternative modeled target.
