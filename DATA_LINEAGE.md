# Data lineage — every production metric traced to its source

Every user-facing number is reproducible from committed snapshots plus repository code. No metric is hand-entered. The refresh pipeline (`npm run data:refresh`) rewrites the snapshots from the authoritative endpoints; validation (`npm run data:validate`) gates every refresh.

## Snapshots

| File | Source endpoint | Series | Frequency | Transform on load |
|---|---|---|---|---|
| `data/debt-latest.json` | `api.fiscaldata.treasury.gov/.../debt_to_penny?sort=-record_date&page[size]=5` | Debt to the Penny | business daily | none (verbatim response) |
| `data/historical-debt.csv` | `fred.stlouisfed.org/graph/fredgraph.csv?id=GFDEBTN` | Total public debt | quarterly EOP | ×1e6 (millions→$); re-dated quarter-start → true quarter-end (`lib/data.ts quarterEnd`) |
| `data/transitions.json` | `.../debt_to_penny?filter=record_date:lte:<inauguration>` | exact boundary balances | per transition (2001+) | none |
| `data/cpi.csv` | `fredgraph.csv?id=CPIAUCSL` | BLS CPI-U | monthly | missing cells ("."/empty) dropped explicitly (`lib/fred.ts`) |
| `data/gdp.csv` | `fredgraph.csv?id=GDP` | BEA nominal GDP (SAAR) | quarterly | ×1e9 (billions→$) |
| `data/population.csv` | `fredgraph.csv?id=POPTHM` | Census/BEA population | monthly | ×1e3 (thousands→persons) |
| `data/fiscal-receipts.csv` | `fredgraph.csv?id=FYFR` | OMB federal receipts | annual FY | ×1e6 |
| `data/fiscal-outlays.csv` | `fredgraph.csv?id=FYONET` | OMB federal net outlays | annual FY | ×1e6 |
| `data/model-evaluation.json` | generated by `scripts/evaluate-models.ts` from `historical-debt.csv` | walk-forward artifact | on refresh | deterministic given data |

## Displayed metrics

| Metric (where) | Computation | Code |
|---|---|---|
| Total/public/intragov debt (home, overview, `/api/latest`) | fields of latest Treasury row | `lib/data.ts latest()` |
| Historical trajectory (all charts) | GFDEBTN × 1e6, quarter-end dated | `lib/data.ts history()` |
| Real (2025 $) debt values (history, overview, admin table) | nominal × (2025 avg CPI ÷ CPI at obs month) | `lib/inflation.ts toReal()` |
| Administration start/end/increase/%/CAGR/per-day (admin page, `/api/administrations`) | exact daily balance (2001+) or preceding quarter-end; rates over actual as-of dates; nominal + 2025-$ variants | `lib/data.ts summarize()` |
| Forecast midpoint (forecast page, home, `/api/forecast`) | production model from `data/model-evaluation.json` refit on full series | `lib/data.ts forecast()`, `lib/models.ts` |
| Forecast range | last obs × (1 + model growth + q10/q90)^years; quantiles = out-of-sample 5y growth errors | same |
| Model comparison table (forecast page) | rendered from `data/model-evaluation.json` | `app/forecast/page.tsx` |
| Per resident (overview, scenario) | debt ÷ POPTHM at snapshot month | `lib/macro.ts populationAt()` |
| Debt-to-GDP (overview, scenario) | nominal debt ÷ nominal GDP, same period (no deflation needed — documented) | `lib/macro.ts gdpAt()` |
| Scenario paths (`/api/scenario`, Scenario Lab) | deterministic identity from Treasury/BEA/OMB/Census baselines; engine shared client/server | `lib/scenario.ts`, `lib/baseline.ts` |
| Year-over-year (overview) | latest ÷ aligned prior-year observation − 1 | `app/overview/page.tsx` |

## Known data caveats

- **CPI October 2025 is absent upstream** (never published due to the federal shutdown); the 2025 base-year average uses the 11 published months, and the loader refuses fewer than 10.
- GFDEBTN rows are end-of-period values dated by quarter start on FRED; everything downstream uses re-dated quarter ends.
- Debt to the Penny begins 1993-04-01, so exact transition balances exist from the 2001 inauguration onward; earlier boundaries are labeled quarter-end proxies in the UI.
- GFDEBTN begins 1966-Q1; administrations that started earlier (Johnson and before) are excluded rather than backfilled.
